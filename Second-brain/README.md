# 🧠 Second Brain — Bachelor Informatique

Système de gestion des connaissances (cours, IA, alternance et projets) propulsé par **Obsidian** et versionné avec **Git**.

## 🗂️ Architecture
- **00-Accueil.md** : Tableau de bord principal pour la navigation.
- **00-Inbox/** : Capture rapide (brouillons et idées en vrac).
- **01-Ecole/** : Cours de 1re année, IA, prompt engineering et bibliothèque de prompts.
- **02-Alternance/** : Suivi des missions en entreprise, réunions et procédures.
- **03-Projets/** : TPs, code et projets personnels.
- **04-Archives/** : Éléments terminés.
- **99-Templates/** : Modèles de notes prêts à l'emploi.
