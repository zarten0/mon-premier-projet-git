## 3 Regles Obligatoires
1. Aucune donnee personnelle dans un prompt (ni la tienne, ni celle d’un camarade, ni un document d’ecole/entreprise).
2. Aucun compte impose : le labo du cours (Mistral) + Duck.ai/Compar:IA fonctionnent sans compte.
3. Verifier avant de croire : une reponse d’IA est une proposition, pas une source. Tout ce qui est garde dans le kit doit indiquer ce qui a ete verifie.

---

## Definitions a Connaître

**IA** : Programmes qui font des taches associees a l’intelligence humaine.

**ML (Machine Learning)** : La machine apprend a partir d’exemples (pas de regles codees).

**LLM (Large Language Model)** : Predit le token suivant, entraine sur des milliards de textes. Exemples : GPT-4, Mistral Large.

**Token** : Unite de base pour l’IA (1 mot = environ 1 token).

**Fenêtre de contexte** : Memoire de l’IA (ex: 32K tokens = environ 24 000 mots). Au-dela, elle oublie tout.

**Température** : 0.1-0.3 = reponses deterministes / 0.7-1.0 = reponses creatives (mais moins fiables).

---

## 5 Limites de l’IA

1. **Fenêtre de contexte** : L’IA oublie ce qui depasse sa memoire.
2. **Date de coupure** : Elle ne connait rien apres son entrainement (ex: GPT-4, coupure en 2023).
3. **Hallucinations** : Elle peut inventer des faits (citations, dates, noms) avec confiance. Toujours verifier.
4. **Biais** : Elle reproduit les biais de ses donnees (ex: GPT-3 associe 83% des metiers au masculin).
5. **Complaisance** : Elle a tendance a te donner raison (+49% d’approbation vs humains, etude Science 2026).

## Comment Bien Prompter

### Methode CO-STAR
- **Contexte** : Qui suis-je ? Dans quel cadre ?
- **Objectif** : Qu’est-ce que je veux obtenir ?
- **Style** : Quel ton ? Quelle forme ?
- **Tâche** : Quelle est la demande precise ?
- **Auditoire** : Pour qui ?
- **Résultat** : Comment je saurai que c’est bon ?

### Autres methodes utiles
- **Few-shot** : Donner 2-3 exemples du resultat attendu dans le prompt.
- **Chain-of-Thought** : Demander a l’IA de reflexionner etape par etape.
- **Flipped Interaction** : L’IA te pose des questions pour clarifier ta demande.

### A eviter
- "Etape par etape" : Inutile sur les modeles a raisonnement (ils le font deja).
- "TU ES UN EXPERT" : Peut provoquer des excess de confiance.
- Majuscules/emojis : Pas d’impact prouve sur la qualite.

## Exemple de Prompt Optimise

**Mauvais** : "Explique-moi les LLM."

**Bon** :
```
Contexte : Je suis un etudiant en B1 en informatique.
Objectif : Comprendre ce qu’est un LLM et comment il fonctionne.
Style : Simple, avec des analogies.
Tâche : Definir un LLM, son fonctionnement (tokens, vecteurs), et ses limites.
Auditoire : Moi (niveau debutant).
Résultat : Je dois pouvoir l’expliquer a un camarade sans utiliser d’IA.
Format : 3 paragraphes max.
```

## A Retenir
- L’IA predit, elle ne comprend pas. Toujours verifier ses reponses.
- Un bon prompt = un brief clair : Objectif + Public + Format + Critere + Boucle.
- L’effet d’une astuce depend du modele. Mesurer, pas croire.
