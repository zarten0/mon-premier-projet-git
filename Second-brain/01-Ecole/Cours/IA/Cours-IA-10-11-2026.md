## 3 Regles Obligatoires

1. **Aucune donnee personnelle dans un prompt**
   - Ni la tienne, ni celle d'un camarade, ni un document d'ecole ou d'entreprise.
   - *Pourquoi* : Recommandation CNIL. Les offres grand public (ChatGPT, etc.) peuvent reutiliser tes conversations pour entrainer leurs modeles.

2. **Aucun compte impose**
   - Le labo de prompts du cours (modeles Mistral) fonctionnent sans compte.
   - Duck.ai et Compar:IA aussi. Si tu as deja un compte perso (OpenAI, etc.), tu peux l'utiliser.

3. **Verifier avant de croire**
   - Une reponse d'IA est une **proposition**, pas une source.
   - *Toujours indiquer* dans ton kit ce qui a ete verifie (ex: "Source : [lien] + lecture laterale OK").

## Definitions a Connaître par Coeur

### Concepts de base

**Intelligence Artificielle (IA)**
Programme informatique capable d'accomplir des taches qui requierent normalement l'intelligence humaine (comprendre, generer du texte, raisonner).
*Exemple* : ChatGPT, Mistral, Claude.

**Machine Learning (ML) / Apprentissage automatique**
Branche de l'IA ou la machine **apprend a partir de donnees** au lieu de suivre des regles predefinies.
*Exemple* : Modele qui predit le prix d'une maison en analysant des centaines de ventes.

**Large Language Model (LLM) / Grand Modele de Langage**
Modele d'IA specialise dans le traitement du langage naturel. Il **predit le mot (token) suivant** dans une phrase en se basant sur des milliards de textes lus pendant son entrainement.
*Exemples* : GPT-4 (OpenAI), Mistral Large, Llama 3 (Meta), Claude 3 (Anthropic).

**Token**
Unite de base utilisee par les LLM. Peut etre un mot complet ("bonjour"), une partie de mot ("re" + "bonjour"), ou un signe de ponctuation.
*Exemples* :
- "IA" = 1 token
- "Intelligence" = 1 token
- "Artificielle" = 1 token
- "Bonjour !" = 2 tokens ("Bonjour" + " !")

### Fonctionnement des LLM

**Fenêtre de contexte**
"Memoire" du modele. C'est le nombre maximum de tokens que l'IA peut prendre en compte en une seule fois.
*Exemples* :
- Mistral Large : 32K tokens (~24 000 mots)
- GPT-4 : 128K tokens (~100 000 mots)
- *Conséquence* : Tout ce qui depasse cette limite est **oublié** par l'IA.

**Temperature**
Parametre qui controle la creativite des reponses :
- **0.0-0.3** : Reponses deterministes (toujours les memes pour un meme prompt). Utile pour des taches factuelles.
- **0.7-1.0** : Reponses plus creatives et variees, mais potentiellement moins fiables. Utile pour la generation de texte.
- *Recommandation* : Commence avec 0.7 et ajuste selon le besoin.

**Modeles a raisonnement**
LLM qui **ecrivent un brouillon cache** avant de donner leur reponse finale. Meilleurs pour les taches de logique, maths et code.
*Exemples* : Mistral Large, GPT-4, Claude 3.

## Les 5 Limites Fondamentales de l'IA

1. **Fenêtre de contexte limitee**
   L'IA ne peut pas se souvenir de tout. Une conversation trop longue se degrade.
   *Solution* : Resume les points importants periodiquement.

2. **Date de coupure (cutoff)**
   L'IA ne connait **rien** des evenements posterieurs a sa date d'entrainement.
   *Exemples* :
   - GPT-4 : coupure en octobre 2023
   - Mistral Large : coupure en octobre 2023
   - *Conséquence* : Pour des infos recentes, utilise des outils avec acces web (Perplexity, Duck.ai).

3. **Hallucinations**
   L'IA peut **inventer** des informations (dates, noms, faits) avec une totale confiance.
   *Exemple* : Demander "Quels sont les laureats du Prix Nobel de physique 2026 ?" → l'IA inventera des noms.
   *Solution* : **Toujours verifier** avec une source fiable.

4. **Biais (Bias)**
   L'IA reproduit les biais presents dans ses donnees d'entrainement.
   *Exemples* :
   - GPT-3 associe 83% des 388 metiers testes au masculin.
   - Llama 2 n'a que 0.16% de donnees en francais (2023).
   - Les reponses sont souvent centrees sur la culture americaine/anglaise.
   *Solution* : Teste avec differentes formulations et verifie les stereotypes.

5. **Complaisance (Syndrome du "Yes Man")**
   L'IA a tendance a **etre d'accord** avec l'utilisateur, meme si sa demande est problematique.
   *Chiffre* : +49% d'approbation vs des humains (etude Science, mars 2026).
   *Solution* : Demande explicitement : "Quels sont les arguments contre cette idee ?".

## Comment Bien Prompter : Methode CO-STAR

La methode **CO-STAR** est un cadre pour ecrire des prompts efficaces. Chaque lettre represent une etape a preciser :

**C - Contexte**
Qui suis-je ? Dans quel cadre je fais cette demande ?
*Exemple* : "Je suis un etudiant en B1 en informatique."

**O - Objectif**
Qu'est-ce que je veux obtenir exactement ?
*Exemple* : "Comprendre le fonctionnement des LLM."

**S - Style**
Quel ton et quelle forme souhaite-je ?
*Exemple* : "Simple, avec des analogies et des exemples concrets."

**T - Tache**
Quelle est la demande precise ?
*Exemple* : "Definir un LLM, expliquer comment il fonctionne (tokens, vecteurs), et lister ses limites."

**A - Auditoire**
Pour qui est destine cette reponse ?
*Exemple* : "Un etudiant de niveau debutant."

**R - Resultat**
Comment je saurai que c'est bon ?
*Exemple* : "Je dois pouvoir expliquer ce concept a un camarade sans utiliser d'IA."

## Exemple Complet de Prompt Optimise

**Mauvais prompt** (trop vague) :
```
Explique-moi les LLM.
```

**Bon prompt** (methode CO-STAR) :
```
Contexte : Je suis un etudiant en B1 en informatique qui debute dans l'IA.
Objectif : Comprendre ce qu'est un LLM et comment il fonctionne.
Style : Simple et pedague, avec des analogies et 2 exemples concrets.
Tache : 
- Definir un LLM
- Expliquer son fonctionnement (tokens, vecteurs, fenetre de contexte)
- Lister ses 3 principales limites
Auditoire : Moi, niveau debutant.
Resultat : Je dois pouvoir resumer ce concept a voix haute sans notes.
Format : 3 paragraphes maximum + un schema mental.
```

## Autres Methodes de Prompting Utiles

### Few-shot Prompting
Donner **2-3 exemples** du resultat attendu dans le prompt pour guider l'IA.

*Exemple* :
```
Classifie les fruits suivants comme "doux" ou "acide" :
- Pomme : doux
- Citron : acide
- Banane : 
```
*L'IA comprendra le pattern et repondra "doux".*

### Chain-of-Thought (CoT)
Demander a l'IA de **reflechir etape par etape** avant de donner sa reponse.

*Exemple* :
```
Resous ce probleme de maths etape par etape : Si un train parcourt 300 km en 2 heures, quelle est sa vitesse moyenne ?
```

### Flipped Interaction
**L'IA te pose des questions** pour clarifier ta demande ou t'aider a reviser.

*Exemple* :
```
Pose-moi 5 questions pour tester ma comprehension des LLM.
```

## A Eviter dans tes Prompts

1. **"Pense etape par etape"**
   - Inutile sur les modeles a raisonnement (Mistral Large, GPT-4) : ils le font deja automatiquement.
   - Peut etre utile sur les petits modeles.

2. **"TU ES UN EXPERT" ou "TU ES UN PROFESSIONNEL"**
   - Peut provoquer des **exces de confiance** dans les reponses (guide officiel Anthropic).
   - Mieux vaut preciser le domaine : "Tu es un expert en machine learning."

3. **Majuscules et emojis excessifs**
   - Pas d'impact prouve sur la qualite des reponses.
   - Peut rendre le prompt moins lisible.

4. **Prompts trop longs**
   - L'IA se concentre sur les **derniers elements** de la fenetre de contexte.
   - Mieux vaut etre **concise et precise**.

## A Retenir Absolument

1. **L'IA predit, elle ne comprend pas**
   Elle genere la suite la plus plausible, pas une reponse "intelligente".

2. **Un bon prompt = un brief clair**
   Plus tu es precis sur ton objectif, ton public et tes criteres, meilleure sera la reponse.

3. **Toujours verifier**
   Une reponse d'IA n'est pas une source fiable. Utilise des outils de verification (lecture laterale, sources officielles).

4. **L'effet d'une astuce depend du modele**
   Ce qui marche avec GPT-4 peut ne pas marcher avec Mistral. **Teste et mesure** pluttot que de croire.

5. **L'IA est un outil, pas une solution magique**
   Elle peut t'aider a produire plus, mais pas necessairement a comprendre plus.
