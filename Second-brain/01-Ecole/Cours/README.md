# Cours - Sup de Vinci B1

Ce dossier contient tous les **cours et supports pedagogiques** de ton annee en Bachelor 1.

## Organisation

Chaque matiere ou theme a son propre dossier. Par exemple :

```
Cours/
├── IA/                  # Intelligence Artificielle et Prompt Engineering
│   └── Cours-IA-10-11-2026.md
├── Maths/              # (A creer si besoin)
├── Programmation/      # (A creer si besoin)
└── ...
```

## Comment naviguer ?

1. **Trouver un cours** : Cherche le dossier correspondant a la matiere.
2. **Dans chaque dossier** : Les fichiers sont nommes avec la date et le titre du cours.
3. **Format** : Tous les fichiers sont en Markdown (.md) pour une lecture facile dans Obsidian.

## Conseils

- **Nomme tes fichiers** de maniere claire : `Matiere-Titre-Date.md`
- **Utilise des tags** dans tes notes pour les retrouver facilement (ex: `#ia #prompt-engineering #formation`)
- **Lie tes notes** entre elles avec `[[Nom de la note]]` pour créer un reseau de connaissances.
